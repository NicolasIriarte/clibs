# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

**Read [GUIDELINES.md](GUIDELINES.md) at the start of every session working on this repo, and follow it
as a hard constraint, not a suggestion.** It covers branch/PR naming, what requires an issue, how tags
are named, the self-attribution rule (absolute -- see there), and what an AI model may and may not do on
its own (moving issue state, implementing, merging). Where anything else seems to disagree with it,
GUIDELINES.md wins.
